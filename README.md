# Resume Screening System

## Overview

The Resume Screening System is an AI-powered web application that helps recruiters automatically analyze and rank resumes based on job descriptions. The system extracts information from resumes, compares candidate skills with job requirements, and provides a matching score to simplify the hiring process.

## Features

* Upload resumes in PDF format
* Extract text from resumes automatically
* Analyze candidate skills
* Compare resumes with job descriptions
* Generate matching scores
* Rank candidates based on suitability
* User-friendly web interface

## Installation

1. Clone the repository:
   git clone <repository-url>

2. Navigate to the project folder:
   cd Resume_Screening_System

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   python app.py

5. Open your browser and visit:
   http://localhost:5000

## How It Works

1. Upload a resume.
2. Enter a job description.
3. The system extracts text from the resume.
4. Skills and keywords are analyzed.
5. A matching score is generated.
6. Candidates are ranked according to relevance.
